# Rapport de récupération StopFlow

## Base officielle retrouvée

Le fichier transmis est intitulé dans son code :

**StopFlow — Colruyt & Leloup v0.2.2**

Il constitue désormais la base officielle du projet. Il s’agit d’une application
autonome monofichier : HTML, CSS, JavaScript, images intégrées et moteur PDF sont
regroupés dans un seul `index.html`.

- écran de connexion ;
- comptes Responsable et Employé de démonstration ;
- tableau de bord ;
- inventaires ;
- historique ;
- articles ;
- suggestions ;
- paramètres ;
- fournisseurs Colruyt et Leloup ;
- logos intégrés en base64 ;
- stockage dans le navigateur ;
- génération d’un vrai PDF ;
- ouverture et téléchargement distincts du PDF ;
- impression dans une fenêtre dédiée ;
- migration de données ;
- normalisation « Le Loup » vers « Leloup ».

## Traitement réalisé

- copie originale conservée sans modification ;
- création d’un `index.html` V0.2.3 fondé sur ce fichier exact ;
- aucune reconstruction de l’interface ;
- aucun passage artificiel à React ou Next.js ;
- ajout de la documentation de reprise et du plan de future migration.
